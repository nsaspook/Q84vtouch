\doxysection{simple\+\_\+publisher.\+c}
\hypertarget{simple_publisher_8c-example}{}\label{simple_publisher_8c-example}A simple program to that publishes the current time whenever ENTER is pressed.

Usage\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{./bin/simple\_publisher\ [address\ [port\ [topic]]]}

\end{DoxyCode}


Where {\ttfamily address} is the address of the MQTT broker, {\ttfamily port} is the port number the MQTT broker is running on, and {\ttfamily topic} is the name of the topic to publish with. Note that all these arguments are optional and the defaults are {\ttfamily address} = {\ttfamily "{}test.\+mosquitto.\+org"{}}, {\ttfamily port} = {\ttfamily "{}1883"{}}, and {\ttfamily topic} = "{}datetime"{}.
